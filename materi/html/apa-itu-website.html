Apa itu website

Website adalah kumpulan halaman yang bisa dibuka lewat alamat di browser. Sebelum menulis kode, kenali dulu bagian-bagiannya.

Satu alamat, banyak halaman

Halaman web adalah dokumen yang ditampilkan browser: teks, gambar, dan tautan yang bisa kamu klik. Browser adalah program untuk membukanya, seperti Chrome, Firefox, Safari, atau Edge. Website adalah kumpulan halaman seperti itu yang saling terhubung dan biasanya berada di bawah satu nama, misalnya sekolahku.sch.id.

Halaman beranda, profil sekolah, dan daftar guru bisa jadi tiga halaman berbeda, tetapi semuanya bagian dari satu website. Tautan di antara halaman itulah yang membuat pengunjung bisa berpindah tanpa mengetik alamat baru.

Internet dan web bukan hal yang sama

Internet adalah jaringan komputer yang saling terhubung di seluruh dunia. Jaringan ini dipakai banyak layanan sekaligus: surel, panggilan video, permainan online, dan web.

Web adalah salah satu layanan di internet: kumpulan dokumen yang diakses lewat HTTP atau HTTPS lalu ditampilkan browser. Semua halaman web ada di internet, tetapi tidak semua isi internet adalah web.

Sehari-hari orang sering berkata “buka internet” padahal maksudnya “buka website”. Dua istilah itu dipakai bergantian, tetapi secara teknis berbeda.

Tiga bahasa, tiga tugas

Hampir semua halaman web dibangun dari tiga bahasa yang bekerja bersama. Kamu tidak perlu menguasainya sekaligus.

  • HTML menyusun isi: judul, paragraf, gambar, tautan, dan daftar.
  • CSS mengatur tampilan: warna, ukuran huruf, jarak, dan tata letak.
  • JavaScript menambah perilaku: merespons klik, memeriksa isian formulir, atau mengambil data baru.

Dua baris HTML sudah cukup untuk menampilkan judul dan paragraf. Tampilannya masih polos karena belum ada CSS.

Mulai dari HTML

Tanpa HTML tidak ada halaman yang bisa ditampilkan. CSS dan JavaScript menempel pada HTML, jadi urutan belajarnya memang HTML dulu.

Website statis dan dinamis

Kalau semua pengunjung melihat isi yang sama, website itu statis. Contohnya portofolio atau halaman profil sekolah. Kalau server menyusun isi berbeda untuk setiap permintaan, website itu dinamis — misalnya beranda media sosial yang menampilkan unggahan terbaru.

Website Webiko yang sedang kamu baca ini statis: berkas HTML-nya sudah jadi dan dikirim apa adanya. Nanti, saat belajar JavaScript, kamu akan melihat halaman statis tetap bisa berubah setelah dibuka di browser.

Yang kamu butuhkan

Untuk mulai, kamu hanya perlu browser dan editor teks. Di Windows, Notepad sudah cukup; kalau mau lebih nyaman, pakai editor gratis seperti Visual Studio Code.

Tidak ada framework, paket, atau aplikasi tambahan yang harus dipasang untuk sepuluh bab ini. Semua berkas ditulis sebagai teks biasa dan disimpan dengan akhiran .html.

Cek pemahaman

Tiga pertanyaan

Jawab dulu di kepalamu, baru buka kuncinya.

  1. Apa bedanya internet dan web?

    Lihat jawaban

    Internet adalah jaringan komputernya. Web adalah salah satu layanan yang berjalan di atas internet, diakses lewat HTTP atau HTTPS dan ditampilkan browser.

  2. Satu website punya beranda, profil, dan daftar guru. Itu satu website atau tiga?

    Lihat jawaban

    Satu website, selama halamannya saling terhubung dan biasanya berada di bawah satu domain, misalnya sekolahku.sch.id.

  3. Halaman profil sekolah menampilkan isi yang sama untuk semua pengunjung. Termasuk statis atau dinamis?

    Lihat jawaban

    Statis. Server mengirim berkas yang sudah jadi. Website dinamis menyusun isi berbeda untuk setiap permintaan.

Rangkuman

  • Website adalah kumpulan halaman web yang saling terhubung dan biasanya berada di bawah satu domain.
  • Internet adalah jaringan komputernya; web adalah salah satu layanan yang berjalan di atasnya.
  • HTML menyusun isi, CSS mengatur tampilan, JavaScript menambah perilaku.
  • Website statis menampilkan isi yang sama; website dinamis menyusun isi berbeda untuk setiap permintaan.
