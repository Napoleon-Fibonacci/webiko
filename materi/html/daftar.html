HTML dari nol · Bab 8 dari 10

Daftar berurutan dan tidak

Daftar dipakai saat informasi terdiri dari beberapa butir. HTML menyediakan tiga jenis daftar, dan masing-masing punya arti.

Daftar tidak berurutan

Pakai <ul> kalau urutan butirnya tidak penting. Setiap butir dibungkus <li>.

index.html HTML 
<ul>  <li>Buku tulis</li>  <li>Pensil</li>  <li>Penghapus</li></ul>

Browser menampilkan butir dengan tanda bulat. Mengganti urutan buku, pensil, dan penghapus tidak mengubah artinya.

Daftar berurutan

Pakai <ol> kalau urutan butirnya penting, misalnya langkah-langkah. Browser memberi nomor otomatis, jadi kamu tidak perlu menulis “1.” sendiri.

index.html HTML 
<ol>  <li>Buka berkas HTML di editor.</li>  <li>Tulis isi halaman di dalam body.</li>  <li>Simpan, lalu muat ulang browser.</li></ol>

Kalau langkah kedua dan ketiga ditukar, hasilnya bisa berbeda. Karena itu dipakai <ol>, bukan <ul>.

Daftar bersarang

Daftar boleh berada di dalam daftar. Tempatkan daftar anak di dalam <li> milik induknya, bukan langsung di dalam <ul> atau <ol>.

index.html HTML 
<ul>  <li>Alat tulis    <ul>      <li>Pensil</li>      <li>Penggaris</li>    </ul>  </li>  <li>Buku</li></ul>

“Alat tulis” punya daftar kecil di dalamnya. Perhatikan bahwa <ul> anak berada sebelum </li> induknya.

Daftar deskripsi

Untuk pasangan istilah dan penjelasannya, pakai <dl>. Istilah ditulis dengan <dt>, penjelasannya dengan <dd>.

index.html HTML 
<dl>  <dt>HTML</dt>  <dd>Bahasa penanda untuk menyusun isi halaman.</dd>  <dt>CSS</dt>  <dd>Bahasa untuk mengatur tampilan halaman.</dd></dl>

Cocok untuk kamus kecil, daftar istilah, atau pasangan pertanyaan dan jawaban singkat.

Kapan pakai yang mana

  • Urutan penting: <ol>.
  • Urutan tidak penting: <ul>.
  • Pasangan istilah dan penjelasan: <dl>.
  • Menu navigasi juga sering memakai <ul> karena daftar tautan memang kumpulan butir.
Jangan membuat butir palsu

Menulis tanda minus atau angka lalu menekan Enter bukan daftar bagi browser. Tanpa <ul>, <ol>, dan <li>, pembaca layar tidak tahu bahwa itu kumpulan butir.

Latihan langsung

Daftar tugas

Isi daftar alat, langkah pengerjaan, dan satu istilah beserta artinya. Ubah kode di panel kiri, lalu klik Jalankan. Tidak perlu membuat file.

>_ tugas.html bisa diubah
Hasil pratinjau

Isi setiap komentar, lalu klik Jalankan.

Cek hasil:

  • Setiap butir dibungkus <li>.
  • Langkah berurutan memakai <ol>.
  • Istilah dan artinya memakai <dt> dan <dd>.

Tantangan tambahan

Tiga jenis daftar

Buat satu halaman berisi daftar alat sekolah dengan <ul>, langkah menyiapkan tas dengan <ol>, dan dua istilah pelajaran beserta artinya dengan <dl>. Tambahkan satu daftar bersarang di dalam butir alat tulis.

Rangkuman

  • <ul> untuk butir tanpa urutan, <ol> untuk butir berurutan.
  • Setiap butir selalu dibungkus <li>.
  • Daftar bersarang diletakkan di dalam <li> induknya.
  • <dl> berisi pasangan <dt> dan <dd>.

Bacaan asli

  • MDN — ul element
  • MDN — dl element
  • WHATWG — Grouping content
