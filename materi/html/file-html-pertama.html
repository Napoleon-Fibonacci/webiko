HTML dari nol · Bab 3 dari 10

File HTML pertamamu

Satu berkas teks sudah cukup untuk membuat halaman web. Simpan, buka di browser, lalu ubah sesukamu.

HTML itu berkas teks

Halaman yang kamu lihat di browser berasal dari berkas teks biasa. Isinya bukan gambar atau aplikasi, melainkan huruf dan tag yang bisa kamu baca serta ubah sendiri.

Akhiran nama berkas menentukan cara komputer memperlakukannya. Berkas .html dibuka browser sebagai halaman web. Berkas .txt hanya dibuka sebagai teks biasa, jadi kodenya terlihat mentah.

Nama index.html biasa dipakai untuk halaman depan. Saat membuka alamat website tanpa nama berkas, server mencari index.html lebih dulu. Untuk latihan, nama itu juga memudahkanmu mengenali halaman utama.

Buat dan simpan berkas

  1. Buka editor teks. Notepad sudah cukup; Visual Studio Code lebih nyaman karena tag berwarna.
  2. Tulis kerangka HTML5 seperti di bagian berikutnya.
  3. Pilih File > Save As, lalu beri nama index.html.
  4. Di Notepad, ubah Save as type menjadi All Files. Kalau tidak, berkas bisa tersimpan sebagai index.html.txt.
  5. Simpan di folder khusus, misalnya latihan-web, dan pastikan berkas disimpan dengan encoding UTF-8.
Satu folder, satu halaman

Simpan semua berkas latihan di satu folder. Nanti, saat menambahkan gambar atau halaman lain, alamatnya cukup ditulis relatif terhadap folder itu.

Kerangka yang harus ada

Halaman HTML5 minimal memuat kerangka ini. Tanpa <body>, tidak ada isi yang tampil; tanpa <head>, judul tab dan encoding bisa bermasalah.

index.html HTML 
<!DOCTYPE html><html lang="id"><head>  <meta charset="UTF-8">  <title>Halaman pertamaku</title></head><body>  <h1>Halo, dunia!</h1>  <p>Ini halaman pertamaku.</p></body></html>

Baris <h1> dan <p> adalah isi halaman. Ganti keduanya dengan tulisanmu sendiri.

  • <!DOCTYPE html> menandai berkas sebagai HTML5.
  • <html lang="id"> membungkus seluruh halaman.
  • <head> memuat keterangan yang tidak tampil, kecuali judul pada tab.
  • <body> memuat semua isi yang terlihat.

Buka di browser

  1. Buka folder tempat index.html disimpan.
  2. Klik dua kali berkas itu, atau seret berkasnya ke jendela browser.
  3. Alamat di bilah browser akan dimulai dengan file:///, bukan https://.
  4. Setelah mengubah kode, simpan berkas lalu muat ulang halaman dengan F5 atau Ctrl + R.
Alamat file:/// itu wajar

Halaman yang dibuka langsung dari komputermu belum melewati server. Karena itu alamatnya berupa lokasi berkas, bukan nama domain. Halaman tetap tampil, hanya belum bisa diakses orang lain.

Kalau hasilnya tidak sesuai

  • Kode terlihat di halaman. Berkas mungkin tersimpan sebagai .txt atau dibuka lewat editor. Periksa akhirannya, lalu buka ulang di browser.
  • Huruf aneh seperti Ã©. Encoding bukan UTF-8 atau <meta charset="UTF-8"> belum ada. Simpan ulang sebagai UTF-8.
  • Perubahan tidak muncul. Berkas belum disimpan atau browser masih memakai salinan lama. Simpan, lalu muat ulang dengan Ctrl + F5.
  • Judul tab kosong. Isi <title> di dalam <head>.

Latihan langsung

Isi halaman pertamamu

Kerangka di panel kiri sudah siap, tetapi judul dan isinya masih kosong. Lengkapi, lalu klik Jalankan.

  1. Isi <title> dengan Perkenalan.
  2. Di dalam <body>, tambah <h1> berisi nama lengkapmu.
  3. Tambah dua <p>: satu tentang kelas dan sekolahmu, satu tentang hobimu.
>_ index.html bisa diubah
Hasil pratinjau

Halaman masih polos. Isi judul dan body, lalu klik Jalankan.

Cek hasil:

  • <title> berisi teks “Perkenalan”.
  • Ada satu <h1> berisi nama lengkapmu di dalam <body>.
  • Ada dua <p>: satu tentang kelas dan sekolah, satu tentang hobi.

Rangkuman

  • Halaman HTML adalah berkas teks berakhiran .html yang dibuka browser.
  • index.html biasa dipakai sebagai halaman depan.
  • Kerangka minimal berisi <!DOCTYPE html>, <html>, <head>, dan <body>.
  • Simpan sebagai UTF-8, lalu muat ulang browser setiap kali kode berubah.
  • Alamat file:/// berarti halaman dibuka langsung dari komputermu, belum lewat server.
