Mengubah halaman dari kode

Halaman yang kamu lihat tersusun dari elemen. JavaScript bisa memilih elemen itu, lalu mengubah teks, warna, atau kelasnya tanpa memuat ulang halaman.

Memilih elemen

document adalah pintu masuk ke halaman. querySelector memilih elemen pertama yang cocok dengan selector CSS: #judul untuk id, .pesan untuk kelas, atau button untuk nama tag.

pilih.js JS 
const judul = document.querySelector("#judul");console.log(judul.textContent);

Kalau elemennya ada, hasilnya berupa elemen. Kalau selectornya salah, hasilnya null.

Mengubah teks dan warna

textContent mengganti tulisan di dalam elemen. style mengubah gaya langsung. Nama properti CSS yang memakai tanda hubung ditulis tanpa tanda hubung dan huruf berikutnya kapital: background-color menjadi backgroundColor.

ubah.js JS 
const judul = document.querySelector("#judul");judul.textContent = "Halo, Webiko!";judul.style.color = "crimson";

Hasilnya judul baru berwarna merah. Halaman tidak dimuat ulang.

Menambah dan melepas kelas

Untuk perubahan yang besar, lebih rapi menyiapkan kelas di CSS lalu memakai classList. add menambah, remove melepas, dan toggle berganti sesuai keadaan sekarang.

kelas.js JS 
const pesan = document.querySelector(".pesan");pesan.classList.add("sorot");

Kelas sorot sudah diatur di CSS. JavaScript hanya memasang atau melepasnya.

Memilih banyak elemen

querySelectorAll mengembalikan semua yang cocok, bukan satu elemen. Hasilnya bisa diulang dengan for seperti array.

semua.js JS 
const item = document.querySelectorAll(".item");for (let i = 0; i < item.length; i++) {  console.log(item[i].textContent);}

Latihan langsung

Ubah judul dan pesan

Kode berjalan di pratinjau kecil di bawah editor. Di sana document menunjuk halaman pratinjau, bukan halaman materi.

  1. Klik Jalankan. Judul menjadi Halo, Webiko!.
  2. Ganti teks itu menjadi Belajar DOM, lalu jalankan lagi.
  3. Ganti crimson menjadi seagreen, lalu jalankan.

Pratinjau halaman

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Judul di pratinjau berubah menjadi Halo, Webiko!.
  • Pesan berwarna merah dan berlatar kuning.
  • Setelah diganti, judul menjadi Belajar DOM dan pesan berwarna hijau.

Kesalahan umum

  • Lupa tanda selector: judul mencari tag, bukan id. Id butuh #judul, kelas butuh .pesan.
  • Selector tidak cocok sehingga hasilnya null, lalu muncul Cannot read properties of null.
  • Menulis style.background-color. Di JavaScript namanya style.backgroundColor.
  • Menjalankan kode sebelum elemen ada. Letakkan script di akhir <body> atau tunggu halaman selesai dimuat.
  • Mengira querySelectorAll memberi satu elemen; hasilnya daftar, jadi perlu diulang.
  • Memakai innerHTML dengan isian dari pengguna; teks biasa lebih aman memakai textContent.

Rangkuman

  • document.querySelector memilih elemen pertama sesuai selector CSS.
  • textContent mengganti teks; style mengubah gaya langsung.
  • Nama properti gaya memakai camelCase, misalnya backgroundColor.
  • classList.add, remove, dan toggle mengatur kelas.
  • querySelectorAll mengembalikan daftar elemen yang bisa diulang.
