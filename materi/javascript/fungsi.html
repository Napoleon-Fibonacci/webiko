Fungsi

Kode yang dipakai berulang lebih rapi kalau dibungkus menjadi fungsi. Beri nama, kirim nilai, lalu ambil hasilnya.

Membuat dan memanggil fungsi

Fungsi adalah blok kode bernama. Kamu menulisnya sekali, lalu memanggilnya berkali-kali dengan nilai yang berbeda.

sapa.js JS 
function sapa(nama) {  return "Halo, " + nama + "!";}console.log(sapa("Rani")); // "Halo, Rani!"

nama adalah parameter. Nilai "Rani" yang dikirim saat memanggil disebut argumen.

return mengirim hasil keluar dari fungsi. Tanpa return, fungsi tetap berjalan tetapi hasilnya undefined.

Parameter lebih dari satu

Fungsi bisa menerima beberapa parameter, dipisah koma. Urutan argumen harus sama dengan urutan parameter.

luas.js JS 
function luas(panjang, lebar) {  return panjang * lebar;}console.log(luas(5, 3)); // 15

luas(5, 3) mengirim 5 sebagai panjang dan 3 sebagai lebar. Hasilnya 15.

Hasil bisa disimpan

Nilai yang dikembalikan fungsi bisa langsung dicetak atau disimpan di variabel.

simpan.js JS 
const hasil = luas(6, 4);console.log("Luas 6 x 4:", hasil); // 24

Variabel yang dibuat di dalam fungsi hanya hidup di dalam fungsi itu. Di luar fungsi, nama tersebut tidak bisa dipakai.

Latihan langsung

Buat fungsi luas

Lengkapi fungsi di panel kode, lalu klik Jalankan dan cocokkan hasilnya di panel Keluaran.

  1. Ganti return 0; dengan return panjang * lebar;.
  2. Tambah console.log(luas(8, 2)); setelah baris console.log(luas(5, 3));.
  3. Tambah const hasil = luas(6, 4); dan console.log("Luas 6 x 4:", hasil); di akhir kode.
>_ luas.js bisa diubah
Keluaran console

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Baris pertama berisi 15.
  • Baris kedua berisi 16.
  • Baris ketiga berisi Luas 6 x 4: 24.

Kesalahan umum

  • Lupa menulis return, sehingga hasilnya undefined.
  • Menulis nama fungsi tanpa kurung saat memanggil, misalnya luas, bukan luas(5, 3).
  • Tertukar urutan argumen.
  • Menulis nama fungsi berbeda antara saat dibuat dan dipanggil.

Cek pemahaman

Kuis pilihan ganda

Pilih satu jawaban untuk setiap soal, lalu klik Periksa jawaban.

Fungsi tidak menulis return. Apa nilai hasilnya?

Fungsi luas(panjang, lebar) dipanggil luas(5, 3). Nilai apa yang diterima panjang?

Bagaimana cara memanggil fungsi luas?

Rangkuman

  • Fungsi membungkus kode yang dipakai berulang.
  • Parameter adalah nama nilai di dalam fungsi; argumen adalah nilai yang dikirim.
  • return mengirim hasil keluar dari fungsi.
  • Fungsi dipanggil dengan menulis namanya diikuti tanda kurung.
