Membuat daftar dari data

Data jarang datang satu per satu. Daftar murid, nilai, atau pesan biasanya tersimpan sebagai array. JavaScript bisa mengubah array itu menjadi elemen halaman, satu baris untuk setiap isi.

Data berbentuk daftar

Setiap murid punya nama dan kota. Kumpulan murid disimpan sebagai array berisi objek. Dari array ini, halaman perlu membuat satu baris daftar untuk setiap murid.

murid.js JS 
const murid = [  { nama: "Ayu", kota: "Bandung" },  { nama: "Bima", kota: "Surabaya" },  { nama: "Citra", kota: "Makassar" }];

Satu array, tiga objek. Urutan di array menjadi urutan di halaman.

Membuat satu elemen

Untuk menambah baris, buat elemen baru dengan document.createElement. Elemen itu belum terlihat sampai ditempelkan ke halaman memakai append.

satu-item.js JS 
const daftar = document.querySelector("#daftar");const item = document.createElement("li");item.textContent = "Ayu";daftar.append(item);

Tiga langkah: buat, isi teksnya, lalu tempelkan. Tanpa append, elemen hanya ada di memori.

Mengulang dengan forEach

forEach menjalankan fungsi sekali untuk setiap isi array. Di dalamnya, buat satu li, isi dengan data murid, lalu tempelkan ke daftar.

daftar.js JS 
const daftar = document.querySelector("#daftar");murid.forEach(function (orang) {  const item = document.createElement("li");  item.textContent = orang.nama + " - " + orang.kota;  daftar.append(item);});

Nama orang hanya berlaku di dalam fungsi. Setiap putaran mendapat objek berikutnya dari array.

Data dari server

Data dari fetch tiba belakangan. Karena itu daftar dibuat di dalam .then kedua, setelah res.json() selesai. Kosongkan daftar lebih dulu supaya baris lama tidak menumpuk saat kode dijalankan lagi.

dari-server.js JS 
fetch("/data/contoh-kelas.json")  .then(function (res) {    return res.json();  })  .then(function (data) {    daftar.replaceChildren();    data.murid.forEach(function (orang) {      const item = document.createElement("li");      item.textContent = orang.nama;      daftar.append(item);    });  })  .catch(function () {    daftar.textContent = "Data gagal dimuat.";  });

replaceChildren() membuang semua baris lama tanpa menghapus elemen ul-nya. Daftar kosong siap diisi ulang.

Teks atau HTML

Data dari server bisa berisi tanda seperti < atau &. textContent menampilkannya sebagai teks biasa. innerHTML menafsirkannya sebagai HTML, sehingga data asing bisa menyisipkan elemen yang tidak kamu rencanakan. Untuk isi daftar, pakai textContent.

Latihan langsung

Tampilkan daftar murid

Kode berjalan di pratinjau. Di sana document menunjuk halaman pratinjau, bukan halaman materi. Array murid diubah menjadi baris daftar.

Pratinjau hanya punya satu ul, jadi querySelector("ul") cukup untuk menemukannya.

  1. Klik Jalankan. Muncul daftar Ayu, Bima, dan Citra.
  2. Tambah { nama: "Dedi", kota: "Medan" }, sebelum ];, lalu jalankan. Dedi muncul paling bawah.
  3. Ganti orang.nama menjadi orang.kota, lalu jalankan. Yang tampil kota, bukan nama.
  4. Hapus daftar.append(item);, lalu jalankan. Daftar kembali kosong.
  5. Kembalikan baris yang dihapus.

Pratinjau halaman

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Setelah Jalankan, pratinjau berisi tiga baris: Ayu, Bima, Citra.
  • Dengan objek Dedi, daftar menjadi empat baris.
  • Dengan orang.kota, isinya Bandung, Surabaya, Makassar.
  • Tanpa append, daftar tetap kosong.

Kesalahan umum

  • Membuat elemen dengan createElement tetapi lupa append. Elemen tidak pernah masuk halaman.
  • Memakai innerHTML untuk data dari server. Pakai textContent supaya tanda seperti < tampil sebagai teks.
  • Tidak mengosongkan daftar sebelum menggambar ulang, sehingga baris lama menumpuk.
  • Menulis createElement tanpa document di depannya.
  • Mengira forEach mengembalikan array baru. Hasilnya undefined; untuk array baru pakai map.
  • Meletakkan data.murid.forEach di luar .then. Data belum ada saat kode itu berjalan.

Rangkuman

  • Array berisi objek diubah menjadi satu elemen untuk setiap isi.
  • document.createElement("li") membuat elemen baru yang belum tampil.
  • textContent mengisi teks; append menempelkan elemen ke halaman.
  • forEach menjalankan fungsi untuk setiap isi array.
  • replaceChildren() mengosongkan daftar sebelum diisi ulang.
  • Pakai textContent, bukan innerHTML, untuk data yang tidak kamu tulis sendiri.
