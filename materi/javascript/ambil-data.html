Mengambil data dari server

Data seperti daftar siswa atau nilai biasanya tidak ditulis di halaman. Halaman memintanya ke server memakai fetch, lalu server membalas dalam bentuk JSON.

Data dari server

Browser mengirim permintaan, server menjawab dengan teks. Untuk data terstruktur, jawabannya sering berupa JSON: teks yang bentuknya mirip objek dan array JavaScript.

contoh-kelas.json JSON 
{  "kelas": "JavaScript dasar",  "murid": [    { "nama": "Ayu", "kota": "Bandung" },    { "nama": "Bima", "kota": "Surabaya" },    { "nama": "Citra", "kota": "Makassar" }  ]}

Nama kunci memakai tanda kutip karena JSON itu teks, bukan kode JavaScript yang dijalankan.

fetch dan Promise

fetch(alamat) mengirim permintaan. Hasilnya bukan data, melainkan Promise: janji bahwa jawaban akan datang. Fungsi di dalam .then baru berjalan setelah jawaban tiba.

ambil.js JS 
fetch("/data/contoh-kelas.json")  .then(function (res) {    return res.json();  })  .then(function (data) {    console.log(data.kelas);  });

res.json() juga mengembalikan Promise, jadi perlu .then kedua. return wajib ada supaya hasilnya diteruskan.

Menampilkan data di halaman

Setelah data tiba, ubah halaman seperti biasa: pilih elemen, lalu isi textContent. Karena jawaban datang belakangan, perubahan harus dilakukan di dalam .then.

tampil.js JS 
const kelas = document.querySelector("#kelas");const info = document.querySelector("#jumlah");fetch("/data/contoh-kelas.json")  .then(function (res) {    return res.json();  })  .then(function (data) {    kelas.textContent = data.kelas;    const banyak = data.murid.length;    info.textContent = banyak + " murid";  });

data.murid berupa array, jadi jumlahnya dibaca lewat .length.

Kalau permintaan gagal

Jaringan bisa putus atau alamatnya salah. Status 404 tidak otomatis melempar error, jadi periksa res.ok. Tambahkan .catch di ujung untuk menangani kegagalan.

gagal.js JS 
fetch("/data/contoh-kelas.json")  .then(function (res) {    if (!res.ok) {      throw new Error("Status " + res.status);    }    return res.json();  })  .catch(function (galat) {    console.log(galat.message);  });

throw di dalam .then langsung ditangkap .catch di bawahnya.

Latihan langsung

Ambil kelas dari server

Kode berjalan di pratinjau. Pratinjau meminta data lewat halaman materi karena iframe sandbox; di browser asli fetch memanggil server langsung.

  1. Klik Jalankan. Memuat data... berganti menjadi JavaScript dasar dan 3 murid.
  2. Ganti data.kelas menjadi data.murid[0].nama, lalu jalankan lagi. Muncul Ayu.
  3. Ganti alamatnya menjadi /data/tidak-ada.json, lalu jalankan. Muncul Data gagal dimuat.
  4. Kembalikan alamat semula.
>_ kelas.js bisa diubah
Pratinjau halaman

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Setelah Jalankan, pratinjau menampilkan JavaScript dasar dan 3 murid.
  • Dengan data.murid[0].nama, teksnya menjadi Ayu.
  • Alamat yang salah memunculkan Data gagal dimuat. dari .catch.

Kesalahan umum

  • Lupa return res.json(), sehingga data masih berupa Response, bukan isi JSON.
  • Memakai data di luar .then. Kode setelah fetch berjalan lebih dulu, sebelum jawaban tiba.
  • Mengira status 404 otomatis masuk .catch. Periksa res.ok sendiri.
  • Alamat salah atau tanpa garis miring awal, misalnya data/contoh-kelas.json, sehingga dicari di folder halaman.
  • Membuka halaman lewat file://. fetch butuh server, bukan berkas ganda-klik.
  • Tanpa .catch, kegagalan tidak terlihat dan halaman tetap menampilkan teks awal.

Rangkuman

  • fetch(alamat) mengirim permintaan dan mengembalikan Promise.
  • .then pertama menerima Response; res.json() membaca isinya.
  • res.json() juga Promise, jadi butuh .then kedua.
  • res.ok menandai status 200–299; 404 bukan error otomatis.
  • .catch menangani jaringan putus atau isi yang gagal dibaca.
