Array dan objek

Satu variabel bisa menyimpan satu nilai. Untuk menyimpan banyak data sekaligus, pakai array untuk daftar berurutan dan objek untuk data berlabel.

Array: daftar berurutan

Array ditulis dengan tanda kurung siku. Isinya dipisah koma, dan setiap posisi punya nomor yang disebut indeks. Indeks dimulai dari 0, bukan 1.

buah.js JS 
const buah = ["apel", "jeruk", "mangga"];console.log(buah[0]); // apelconsole.log(buah[2]); // manggaconsole.log(buah.length); // 3

buah.length berisi jumlah isi array. Di sini ada tiga buah, jadi indeks terakhirnya 2.

Mengubah dan menambah isi

Isi array bisa diganti lewat indeksnya. push menambahkan nilai baru di paling belakang.

ubah.js JS 
const buah = ["apel", "jeruk"];buah[1] = "pisang";buah.push("mangga");console.log(buah);

Hasilnya array berisi "apel", "pisang", dan "mangga". Urutannya tetap, hanya isinya yang berubah.

Mengulang isi array

Gabungkan array dengan for dari bab sebelumnya. Pakai i < nilai.length, bukan <=, supaya tidak mengambil indeks di luar isi.

ulang-array.js JS 
const nilai = [80, 92, 75];for (let i = 0; i < nilai.length; i++) {  console.log(nilai[i]);}

Mencetak 80, 92, lalu 75.

Objek: data berlabel

Objek ditulis dengan kurung kurawal. Isinya pasangan nama dan nilai, dipisah koma. Pasangan itu disebut properti; namanya dibaca dengan tanda titik.

siswa.js JS 
const siswa = {  nama: "Ayu",  umur: 14,  kelas: "8A",};console.log(siswa.nama); // Ayuconsole.log(siswa.kelas); // 8A

Properti bisa diganti: siswa.umur = 15;. const mengunci variabelnya, bukan isi objeknya.

Array berisi objek

Pola inilah yang nanti dipakai untuk menampilkan daftar dari data: array sebagai wadah, objek sebagai satu baris data.

daftar.js JS 
const siswa = [  { nama: "Ayu", nilai: 90 },  { nama: "Bima", nilai: 80 },];for (let i = 0; i < siswa.length; i++) {  console.log(siswa[i].nama);}

siswa[i] mengambil satu objek, lalu .nama mengambil propertinya.

Kesalahan umum

  • Mengira indeks mulai dari 1. buah[0] adalah isi pertama.
  • Menulis buah.length(); length itu properti, bukan fungsi.
  • Memakai i <= buah.length sehingga putaran terakhir menghasilkan undefined.
  • Tertukar tanda: array pakai [ ], objek pakai { }.
  • Salah ketik nama properti, misalnya siswa.nma, sehingga hasilnya undefined.
  • Mengira const membuat isi array atau objek tidak bisa diubah.

Rangkuman

  • Array menyimpan banyak nilai berurutan; indeksnya mulai dari 0.
  • length memberi jumlah isi; push menambah di belakang.
  • Objek menyimpan data berlabel; properti dibaca dengan titik.
  • Array bisa berisi objek, lalu dibaca dengan siswa[i].nama.
  • Saat mengulang array, pakai i < panjang.
