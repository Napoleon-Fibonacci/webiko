Klik dan isian formulir

Halaman jadi hidup saat menunggu aksi pengunjung: klik tombol, mengetik di kolom, lalu mengirim formulir. JavaScript mendengar aksi itu lewat event.

Menunggu klik

addEventListener memasang pendengar pada elemen. Argumen pertama nama event, misalnya "click". Argumen kedua fungsi yang dijalankan saat event terjadi.

klik.js JS 
const tombol = document.querySelector("#tombol");const judul = document.querySelector("#judul");tombol.addEventListener("click", function () {  judul.textContent = "Tombol diklik!";});

Isi fungsi baru berjalan setelah tombol diklik, bukan saat kode dibaca.

Membaca isian

Kolom isian menyimpan isinya di properti value, bukan textContent. Nilai itu dibaca saat tombol ditekan, jadi selalu mengikuti ketikan terbaru.

sapa.js JS 
const nama = document.querySelector("#nama");const hasil = document.querySelector("#hasil");document.querySelector("#sapa").addEventListener("click", function () {  hasil.textContent = "Halo, " + nama.value + "!";});

Kalau kolom kosong, hasilnya Halo, !. Nilai value selalu berupa teks.

Formulir dan tombol Enter

Di dalam <form>, menekan Enter ikut mengirim formulir. Kejadiannya bernama "submit", bukan "click". Bawaan browser, pengiriman memuat ulang halaman. Panggil preventDefault() untuk membatalkannya.

form.js JS 
const form = document.querySelector("#form");form.addEventListener("submit", function (e) {  e.preventDefault();  // kode lain di sini});

Parameter e berisi info event. e hanya nama, boleh diganti asal konsisten.

Latihan langsung

Sapa dari formulir

Kode berjalan di pratinjau. Setelah menekan Jalankan, coba ketik nama di kolom pratinjau lalu klik Sapa.

  1. Klik Jalankan, lalu ketik Ayu di kolom nama dan klik Sapa. Muncul Halo, Ayu!.
  2. Ganti nama menjadi Bima, klik Sapa lagi. Pesannya ikut berubah.
  3. Hapus baris e.preventDefault();, jalankan, lalu klik Sapa. Pratinjau dimuat ulang dan pesan hilang.
>_ sapa.js bisa diubah
Pratinjau halaman

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Nama Ayu: pesan menjadi Halo, Ayu!.
  • Nama Bima: pesan menjadi Halo, Bima!.
  • Tanpa preventDefault, pratinjau dimuat ulang dan pesan kembali ke contoh awal.

Kesalahan umum

  • Menulis tombol.addEventListener("click", sapa()). Tanda kurung membuat fungsi langsung jalan; tulis sapa tanpa kurung.
  • Memakai nama.textContent untuk kolom isian. Yang benar nama.value.
  • Lupa e.preventDefault() di event submit, sehingga halaman dimuat ulang.
  • Memasang listener submit pada tombol, bukan pada form.
  • Menjalankan querySelector sebelum elemen ada, misalnya script di <head> tanpa menunggu halaman selesai.
  • Menulis selector tanpa tanda: id butuh #, kelas butuh ..

Rangkuman

  • addEventListener("click", fungsi) menjalankan fungsi saat elemen diklik.
  • Isi kolom dibaca lewat value; teks biasa lewat textContent.
  • Formulir memakai event "submit", bukan "click".
  • e.preventDefault() menahan halaman agar tidak dimuat ulang.
  • Pasang listener setelah elemen ada, misalnya script di akhir <body>.
