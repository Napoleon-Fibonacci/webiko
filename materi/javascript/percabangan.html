JavaScript dasar · Bab 4 dari 13

Percabangan if

Kode tidak selalu berjalan lurus. Dengan if, program memilih langkah berdasarkan kondisi yang benar atau salah.

Kondisi bernilai benar atau salah

Perbandingan menghasilkan boolean: true kalau benar, false kalau salah. Hasil inilah yang diperiksa if.

  • === sama persis, termasuk tipe datanya.
  • !== tidak sama.
  • > lebih besar, < lebih kecil.
  • >= lebih besar atau sama dengan, <= lebih kecil atau sama dengan.
banding.js JS 
const umur = 14;console.log(umur >= 13); // trueconsole.log(umur === 15); // false

= mengisi nilai. === membandingkan nilai. Jangan tertukar.

If dan else

Blok di dalam if dijalankan hanya kalau kondisinya true. Kalau false, blok else yang dijalankan.

umur.js JS 
const umur = 14;if (umur >= 13) {  console.log("Boleh masuk SMP");} else {  console.log("Belum cukup umur");}

Hasilnya Boleh masuk SMP karena 14 >= 13 bernilai true.

Beberapa pilihan dengan else if

else if dipakai saat ada lebih dari dua kemungkinan. Kondisi diperiksa dari atas ke bawah. Begitu ada yang true, blok itu dijalankan dan sisanya dilewati.

nilai.js JS 
const nilai = 82;if (nilai >= 90) {  console.log("Sangat baik");} else if (nilai >= 75) {  console.log("Lulus");} else {  console.log("Belum lulus");}

Urutan penting. Kalau nilai >= 75 diperiksa lebih dulu, nilai 92 akan berhenti di Lulus dan tidak pernah mencapai Sangat baik.

Menggabungkan dua kondisi

&& berarti kedua kondisi harus benar. || berarti cukup salah satu yang benar.

remaja.js JS 
const umur = 14;if (umur >= 13 && umur <= 18) {  console.log("Remaja");}

Latihan langsung

Uji tiga nilai

Kode sudah berisi percabangan tiga tingkat. Jalankan, lalu ubah nilai dan jalankan lagi.

  1. Klik Jalankan. Nilai 82 menghasilkan Lulus.
  2. Ganti 82 menjadi 92, lalu jalankan. Hasilnya Sangat baik.
  3. Ganti menjadi 60, lalu jalankan. Hasilnya Belum lulus.
>_ nilai.js bisa diubah
Keluaran console

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Dengan nilai 82, panel Keluaran berisi Lulus.
  • Dengan nilai 92, panel Keluaran berisi Sangat baik.
  • Dengan nilai 60, panel Keluaran berisi Belum lulus.

Kesalahan umum

  • Menulis = saat harus membandingkan dengan ===.
  • Menaruh titik koma setelah kondisi, misalnya if (nilai >= 75);, sehingga blok berikutnya selalu dijalankan.
  • Menyusun else if dari yang paling longgar, sehingga kondisi yang lebih khusus tidak pernah tercapai.
  • Lupa menutup kurung kurawal.
  • Membandingkan isian formulir tanpa mengubahnya menjadi angka: "14" === 14 bernilai false.

Rangkuman

  • if menjalankan blok hanya kalau kondisinya true.
  • else menjadi jalan lain saat kondisi false.
  • else if dipakai untuk beberapa pilihan; urutkan dari kondisi paling khusus.
  • Pakai === untuk membandingkan, bukan =.
  • && butuh dua kondisi benar; || cukup salah satu.
