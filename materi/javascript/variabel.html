Variabel dan tipe data

Kode perlu mengingat nilai: nama, angka, dan pilihan benar atau salah. Variabel adalah wadah bernama untuk menyimpannya.

Menyimpan nilai di variabel

Bayangkan variabel sebagai kotak berlabel. Kamu memberi nama kotak, lalu mengisi nilainya. Saat nilainya dibutuhkan, panggil namanya.

profil.js JS 
const nama = "Rani";let umur = 14;const sukaWeb = true;

const untuk nilai yang tidak diganti, let untuk nilai yang nanti berubah.

Pakai const sebagai pilihan pertama. Ganti ke let hanya kalau nilainya memang perlu diubah. Hindari var di materi baru karena aturan cakupannya lebih membingungkan.

Nama variabel ditulis tanpa spasi, biasanya camelCase: namaLengkap, jumlahKartu. JavaScript membedakan huruf besar dan kecil, jadi nama dan Nama adalah dua variabel berbeda.

Tiga tipe data dasar

  • String: teks, diapit tanda kutip. Contoh "Rani" atau 'SMP Harapan'.
  • Number: angka, tanpa tanda kutip. Contoh 14 atau 3.5.
  • Boolean: hanya true atau false.
tipe.js JS 
const nama = "Rani";const umur = 14;const sukaWeb = true;console.log(typeof nama); // "string"console.log(typeof umur); // "number"console.log(typeof sukaWeb); // "boolean"

typeof mengembalikan nama tipe dalam bentuk string. Ini berguna saat nilai datang dari isian formulir: isian formulir menghasilkan string, termasuk saat kamu mengetik angka.

Mencetak nilai dengan console.log

console.log() menampilkan nilai ke panel Keluaran. Kamu bisa memberi beberapa nilai sekaligus, dipisah koma.

profil.js JS 
console.log("Halo, " + nama + "!");console.log("Umur:", umur);console.log("Suka web:", sukaWeb);

Tanda + menyambung string. Kalau salah satu sisi berupa string, nilai lain ikut diubah menjadi teks. Koma pada console.log hanya memisahkan nilai di keluaran, bukan menggabungkannya.

Mengubah nilai

Variabel let boleh diisi ulang. Variabel const tidak boleh diberi nilai baru setelah dibuat.

ubah.js JS 
let umur = 14;umur = 15;console.log(umur); // 15const nama = "Rani";nama = "Budi"; // error

Baris terakhir sengaja salah. Kalau dijalankan, panel Keluaran menampilkan TypeError karena nama dibuat dengan const.

Latihan langsung

Lengkapi kartu profil

Isi data di panel kode, lalu klik Jalankan untuk melihat hasilnya di panel Keluaran.

  1. Isi nama dengan "Rani".
  2. Isi umur dengan 14.
  3. Tambah const sukaWeb = true;.
  4. Tambah console.log("Umur:", umur); dan console.log("Suka web:", sukaWeb);.
>_ profil.js bisa diubah
Keluaran console

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Panel Keluaran menampilkan Halo, Rani!.
  • Baris kedua berisi Umur: 14.
  • Baris ketiga berisi Suka web: true.

Kesalahan umum

  • Teks ditulis tanpa tanda kutip, sehingga dianggap nama variabel.
  • Salah huruf besar/kecil pada nama variabel.
  • Mengisi ulang variabel const.
  • Lupa menutup tanda kutip atau kurung.

Rangkuman

  • const untuk nilai tetap, let untuk nilai yang berubah.
  • Tipe data dasar: string, number, dan boolean.
  • console.log() membantu memeriksa nilai di panel Keluaran.
  • Nama variabel peka huruf besar/kecil dan biasanya ditulis camelCase.
