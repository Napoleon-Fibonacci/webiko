Menyimpan data di browser

Variabel hilang begitu halaman dimuat ulang. localStorage menyimpan teks di browser, jadi isinya masih ada saat pengunjung membuka halaman lagi.

Variabel hilang, penyimpanan tetap

Variabel hanya hidup selama halaman terbuka. Tekan muat ulang, isinya kembali seperti awal. localStorage menyimpan data per situs di browser, bukan di server, sehingga tidak ikut terkirim otomatis ke server.

simpan.js JS 
localStorage.setItem("tema", "gelap");const tema = localStorage.getItem("tema");console.log(tema);

setItem menulis, getItem membaca. Isinya tetap ada setelah halaman dimuat ulang, bahkan setelah browser ditutup.

Isinya selalu teks

localStorage hanya menyimpan teks. Angka ikut berubah menjadi teks, jadi ubah balik dengan Number() sebelum dihitung. Objek dan array perlu diubah dulu dengan JSON.stringify, lalu dibaca lagi dengan JSON.parse.

angka.js JS 
localStorage.setItem("skor", 87);const skor = Number(localStorage.getItem("skor"));console.log(skor + 1);

Tanpa Number(), hasilnya "871" karena teks disambung, bukan dijumlahkan.

Membaca saat halaman dibuka

Kalau kuncinya belum pernah disimpan, getItem memberi null. Periksa dulu sebelum dipakai, lalu tentukan tampilan awal.

nama.js JS 
const nama = localStorage.getItem("nama");if (nama) {  console.log("Halo, " + nama + "!");} else {  console.log("Belum ada nama.");}

null berarti belum ada, bukan error. Teks kosong "" juga dianggap tidak ada oleh if.

Menghapus simpanan

removeItem menghapus satu kunci. clear menghapus semua data milik situs ini. Jangan simpan password atau data rahasia di localStorage karena isinya bisa dibaca script lain di situs yang sama.

hapus.js JS 
localStorage.removeItem("nama");console.log(localStorage.getItem("nama"));

Hasilnya null. Kunci yang tidak pernah ada juga menghasilkan null, bukan error.

Latihan langsung

Simpan nama di browser

Kode berjalan di pratinjau. Setelah menekan Jalankan, ketik nama lalu klik Simpan. Pratinjau memakai penyimpanan tiruan di dalam sandbox supaya halaman materi tetap aman; di browser asli localStorage menyimpan sungguhan.

  1. Klik Jalankan, ketik Ayu, lalu klik Simpan. Muncul Halo, Ayu!.
  2. Klik Jalankan lagi. Nama Ayu masih muncul karena dibaca saat pratinjau dibuka.
  3. Muat ulang halaman ini, lalu Jalankan. Pilihan tadi masih tersimpan.
  4. Klik Hapus, jalankan lagi. Pesan kembali Belum ada nama.

Pratinjau halaman

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Setelah Simpan, pesan menjadi Halo, Ayu!.
  • Setelah Jalankan lagi atau halaman dimuat ulang, nama yang sama muncul sendiri.
  • Setelah Hapus, pesan kembali Belum ada nama.

Kesalahan umum

  • Memakai hasil getItem langsung tanpa memeriksa null, lalu muncul Halo, null!.
  • Menjumlahkan angka tanpa Number(), sehingga "87" + 1 menjadi "871".
  • Nama kunci tidak sama saat menyimpan dan membaca. Kunci peka huruf besar-kecil.
  • Menyimpan password atau token di localStorage. Script lain di situs yang sama bisa membacanya.
  • Mengira data ikut pindah ke komputer atau browser lain. Isinya hanya ada di browser itu.
  • Menjalankan JSON.parse pada teks kosong atau rusak tanpa try/catch, sehingga muncul SyntaxError.

Rangkuman

  • setItem(kunci, nilai) menyimpan, getItem(kunci) membaca.
  • getItem memberi null kalau kuncinya belum ada.
  • Semua nilai disimpan sebagai teks; angka perlu Number().
  • Isi tetap ada setelah muat ulang, tetapi hanya di browser dan situs itu.
  • removeItem menghapus satu kunci; clear menghapus semua.
