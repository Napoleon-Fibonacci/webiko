Apa itu JavaScript

HTML menyusun isi halaman, CSS mengatur tampilannya, dan JavaScript membuat halaman bisa bereaksi. Ini bahasa yang membuat tombol, menu, dan isian formulir bekerja.

Tiga bahasa, satu halaman

Setiap halaman web yang kamu pakai dibangun dari tiga bagian yang saling melengkapi:

  • HTML menyusun isi: judul, paragraf, gambar, dan tombol.
  • CSS mengatur tampilan: warna, ukuran huruf, dan jarak.
  • JavaScript mengatur perilaku: apa yang terjadi saat tombol diklik atau isian diubah.

Tanpa JavaScript, halaman tetap bisa dibaca. Yang hilang adalah reaksinya: menu tidak terbuka, isian tidak diperiksa, dan tombol tidak mengubah apa pun.

Halaman yang bisa bereaksi

Coba perhatikan halaman ini. Tombol tema di kanan atas dan menu di layar HP bisa berubah karena JavaScript. Contoh lain yang sering kamu temui:

  • Tombol suka yang angkanya bertambah saat diklik.
  • Isian formulir yang menampilkan pesan kalau ada yang kosong.
  • Daftar barang yang menyaring saat kamu mengetik di kotak pencarian.
  • Jam atau hitung mundur yang berubah sendiri.

Semua itu bukan sulap. Ada kode JavaScript yang menunggu kejadian, lalu mengubah halaman.

Contoh pertama

Kode JavaScript bisa menulis pesan ke panel keluaran dengan console.log(). Tanda kutip menandai teks.

halo.js JS 
console.log("Halo, dunia!");console.log("Saya belajar.");

Dua baris kode, dua baris keluaran. Belum ada variabel atau fungsi buatan sendiri.

Latihan langsung

Jalankan kode pertamamu

Kode sudah diisi. Klik Jalankan, lalu lihat panel Keluaran.

  1. Klik Jalankan.
  2. Cocokkan dua baris keluaran dengan contoh di atas.
  3. Ganti teks di dalam tanda kutip, lalu jalankan lagi.
>_ halo.js bisa diubah
Keluaran console

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Baris pertama berisi Halo, dunia!.
  • Baris kedua berisi Saya belajar..

Di mana kode JavaScript ditulis

Kode disimpan di berkas berakhiran .js, lalu dihubungkan ke halaman dengan tag <script>. Letaknya sebelum penutup </body> supaya isi halaman sudah siap.

index.html HTML 
<p>Halo</p><script src="halo.js"></script></body>

Berkas halo.js berisi kode seperti contoh pertama. JavaScript juga bisa ditulis langsung di dalam <script>, tetapi berkas terpisah lebih rapi.

JavaScript bukan Java

Namanya mirip, tetapi keduanya bahasa yang berbeda. JavaScript berjalan di browser dan dipakai untuk halaman web. Java dipakai untuk aplikasi lain, termasuk aplikasi Android. Kamu tidak perlu memasang Java untuk belajar JavaScript.

Kesalahan umum

  • Mengira JavaScript sama dengan Java.
  • Mengharapkan tombol bereaksi padahal JavaScript dimatikan di browser.
  • Menulis kode di berkas .js, tetapi lupa menghubungkannya dengan <script src="...">.
  • Mengira HTML dan CSS bisa menggantikan semua perilaku JavaScript.
