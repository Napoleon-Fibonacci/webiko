JavaScript dasar · Bab 5 dari 13

Perulangan

Menyalin baris yang sama sepuluh kali itu melelahkan. Dengan perulangan, satu blok kode dijalankan berkali-kali sampai kondisinya berhenti.

For: ulang sebanyak yang diketahui

for punya tiga bagian di dalam tanda kurung, dipisah titik koma: nilai awal, syarat berjalan, dan langkah setiap putaran.

ulang.js JS 
for (let i = 1; i <= 5; i++) {  console.log("Putaran " + i);}

Hasilnya lima baris, dari Putaran 1 sampai Putaran 5.

  • let i = 1 — nilai awal, dijalankan sekali.
  • i <= 5 — syarat; dicek sebelum setiap putaran.
  • i++ — langkah; menambah 1 setelah blok selesai.

Menambah lebih dari satu

i++ sama dengan i += 1. Untuk melompat dua angka, pakai i += 2. Langkahnya bebas, asal nilai hitungan akhirnya membuat syarat menjadi false.

genap.js JS 
for (let i = 2; i <= 10; i += 2) {  console.log(i);}

Mencetak 2, 4, 6, 8, 10.

While: ulang selama syarat benar

while hanya memeriksa satu syarat. Cocok kalau jumlah putarannya belum diketahui, misalnya selama stok masih ada.

stok.js JS 
let stok = 3;while (stok > 0) {  console.log("Sisa " + stok);  stok--;}

stok-- mengurangi 1 setiap putaran. Tanpa baris itu, stok tetap 3 dan loop tidak pernah berhenti.

Berhenti di tengah dengan break

break langsung keluar dari loop, walaupun syaratnya masih benar. continue melewati sisa putaran itu dan lanjut ke putaran berikutnya.

berhenti.js JS 
for (let i = 1; i <= 10; i++) {  if (i === 4) {    break;  }  console.log(i);}

Hanya 1, 2, dan 3 yang tercetak.

Latihan langsung

Jumlahkan angka 1 sampai 5

Loop menambahkan setiap angka ke total. Jalankan, lalu ubah batas akhirnya.

  1. Klik Jalankan. Total akhirnya 15.
  2. Ganti i <= 5 menjadi i <= 3, lalu jalankan. Totalnya 6.
  3. Ganti menjadi i <= 10, lalu jalankan. Totalnya 55.

Setiap baris adalah total setelah angka baru ditambahkan.

>_ jumlah.js bisa diubah
Keluaran console

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Batas 5: baris terakhir Total 15.
  • Batas 3: baris terakhir Total 6.
  • Batas 10: baris terakhir Total 55.

Kesalahan umum

  • Lupa menambah hitungan, misalnya i++ tidak ditulis, sehingga loop berjalan terus dan halaman membeku.
  • Syarat yang tidak pernah menjadi false, misalnya i >= 0 dengan langkah i++.
  • Salah batas: i < 5 berhenti di 4, bukan 5. Pakai i <= 5 kalau 5 ikut dihitung.
  • Memakai const untuk variabel hitungan yang diubah, misalnya const i = 1; i++.
  • Mengubah variabel hitungan di dalam blok sehingga langkahnya melompat.

Rangkuman

  • for dipakai saat jumlah putaran sudah diketahui.
  • while dipakai saat berhentinya bergantung pada kondisi.
  • Tiga bagian for: nilai awal, syarat, langkah.
  • Pastikan syarat akhirnya menjadi false, kalau tidak loop tidak berhenti.
  • break keluar dari loop; continue melewati satu putaran.
