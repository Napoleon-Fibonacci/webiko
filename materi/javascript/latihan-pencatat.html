Latihan: pencatat belajar

Semua yang sudah dipelajari bertemu di sini: variabel, array, fungsi, DOM, formulir, penyimpanan, dan penanganan error. Tidak ada sintaks baru. Yang dilatih adalah menyusun potongan-potongan itu menjadi satu aplikasi kecil.

Yang akan dibuat

Pencatat belajar punya isian untuk catatan baru, tombol Tambah, daftar catatan yang bisa dihapus, dan penyimpanan agar catatan tetap ada setelah halaman ditutup. Pratinjau memakai id supaya kode mudah mencari elemennya.

pencatat.html HTML 
<form id="form">  <label for="teks">Catatan baru</label>  <input id="teks" type="text">  <button type="submit">Tambah</button></form><p id="kosong">Belum ada catatan.</p><ul id="daftar"></ul>

Isian, tombol, pesan kosong, dan daftar. Kode JavaScript tinggal mengisi bagian-bagian ini.

Menyiapkan data

Catatan disimpan sebagai array teks. Sebelum dipakai, isi localStorage dibaca. Tempat penyimpanan hanya bisa menyimpan teks, jadi array diubah dengan JSON.stringify saat menulis dan JSON.parse saat membaca.

mulai.js JS 
const KUNCI = "catatan-belajar";let catatan = [];try {  const teks = localStorage.getItem(KUNCI);  catatan = JSON.parse(teks) || [];} catch (galat) {  catatan = [];}

Kalau belum ada simpanan, getItem memberi null, lalu || [] menyiapkan array kosong. Kalau isinya rusak, catch mencegah halaman berhenti.

Menampilkan daftar

Setiap perubahan diakhiri dengan tampil(). Fungsi ini mengosongkan daftar lalu membuat ulang isinya dari array. Cara ini sederhana dan tidak meninggalkan baris lama.

tampil.js JS 
function tampil() {  list.replaceChildren();  catatan.forEach(function (teks, i) {    const item = document.createElement("li");    item.textContent = teks + " ";    const btn =      document.createElement("button");    btn.textContent = "Hapus";    btn.addEventListener("click", function () {      catatan.splice(i, 1);      simpan();      tampil();    });    item.append(btn);    list.append(item);  });  info.hidden = catatan.length > 0;}

textContent menampilkan catatan sebagai teks biasa, bukan HTML. Angka i dipakai tombol Hapus untuk tahu baris mana yang dibuang.

Menambah catatan

Formulir mengirim event submit. Panggil preventDefault agar halaman tidak dimuat ulang. trim membuang spasi di ujung; kalau hasilnya kosong, hentikan proses.

tambah.js JS 
form.addEventListener("submit", function (e) {  e.preventDefault();  const teks = isian.value.trim();  if (!teks) return;  catatan.push(teks);  isian.value = "";  simpan();  tampil();});

Sesudah push, catatan disimpan lalu daftar digambar ulang. Isian dikosongkan supaya siap menerima catatan berikutnya.

Menyimpan dan menghapus

simpan.js JS 
function simpan() {  const teks = JSON.stringify(catatan);  localStorage.setItem(KUNCI, teks);}

Menghapus satu catatan memakai splice(i, 1): mulai dari indeks i, buang satu elemen. Sesudah itu simpan() dan tampil() dipanggil lagi.

Coba sendiri

  • Tambah dua catatan, lalu klik Jalankan lagi. Catatan tetap ada karena tersimpan.
  • Kosongkan isian lalu klik Tambah. Tidak ada baris kosong yang masuk.
  • Hapus semua catatan. Tulisan "Belum ada catatan." muncul kembali.
  • Ganti nilai KUNCI menjadi "catatan-uji". Daftar mulai kosong karena kuncinya berbeda.
  • Tambahkan localStorage.setItem(KUNCI, "bukan json"); di baris pertama, lalu jalankan. try/catch menjaga halaman tetap hidup.

Latihan langsung

Bangun pencatat belajar

Kode di bawah adalah aplikasi lengkapnya. Kode berjalan di pratinjau, dan localStorage di sana disambungkan ke halaman materi supaya data bertahan saat kode dijalankan ulang.

  1. Klik Jalankan. Tulis Belajar loop, lalu klik Tambah. Catatan muncul di daftar.
  2. Tambah Latihan array. Sekarang ada dua baris.
  3. Klik Jalankan lagi. Dua catatan tetap ada karena dibaca dari penyimpanan.
  4. Klik Hapus pada satu baris. Baris hilang dan tetap hilang setelah dijalankan ulang.
  5. Kosongkan isian, lalu klik Tambah. Tidak ada baris kosong.
  6. Klik Atur ulang untuk mengembalikan kode contoh. Catatan yang tersimpan tidak ikut terhapus.
>_ pencatat.js bisa diubah
Pratinjau halaman

Klik Jalankan untuk melihat hasil.

Cek hasil:

  • Dua catatan muncul berurutan di daftar.
  • Jalankan ulang → catatan tetap ada.
  • Hapus satu baris → baris itu hilang dan tidak kembali.
  • Isian kosong → tidak menambah baris.
  • "Belum ada catatan." hilang saat ada isi, muncul lagi saat daftar kosong.

Kesalahan umum

  • Lupa e.preventDefault(), sehingga formulir memuat ulang pratinjau dan catatan di layar hilang.
  • Menyimpan array tanpa JSON.stringify, sehingga bacaan berikutnya bukan array lagi.
  • Lupa JSON.parse saat membaca, lalu memanggil forEach pada teks.
  • Lupa simpan() setelah push atau splice; data hilang saat halaman dimuat ulang.
  • Memakai innerHTML untuk isi catatan; teks seperti <b> berubah menjadi HTML. Pakai textContent.
  • Menghapus dengan indeks yang salah karena daftar tidak digambar ulang sesudah perubahan.

Rangkuman

  • Aplikasi kecil tersusun dari potongan yang sudah dikenal: array, fungsi, event, DOM, dan penyimpanan.
  • Formulir memakai event submit dan preventDefault.
  • Setiap perubahan data diikuti simpan() dan tampil().
  • JSON.stringify dan JSON.parse menjembatani array dengan localStorage.
  • try/catch menjaga aplikasi saat isi penyimpanan rusak.
  • Hapus memakai splice, lalu daftar digambar ulang dari array.
