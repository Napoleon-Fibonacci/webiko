Warna dan latar

HTML menyusun isi halaman. CSS yang menentukan bagaimana isi itu terlihat. Mulailah dari yang paling terlihat: warna teks dan warna latar.

HTML untuk isi, CSS untuk tampilan

HTML memberi tahu browser bahwa sebuah teks adalah judul, paragraf, atau tautan. Ia tidak mengatur warna dan ukuran tampilan. Tugas itu dipegang CSS, singkatan dari Cascading Style Sheets.

Pemisahan ini berguna: satu halaman HTML bisa diberi tampilan yang berbeda tanpa mengubah isinya. Kamu juga tidak perlu menyalin warna yang sama ke setiap tag.

profil.html HTML 
<h1>Profil Rani</h1><p>Aku kelas 8 di SMP Harapan.</p>

HTML hanya menyebut jenis isinya. Tampilannya diatur aturan CSS.

Satu aturan CSS, tiga bagian

Aturan CSS terdiri dari selector, blok deklarasi, dan deklarasi. Selector memilih elemen yang ingin diatur. Di dalam kurung kurawal, tulis properti dan nilainya, lalu akhiri dengan titik koma.

style.css CSS 
h1 {  color: #433fd4;}

h1 adalah selector, color adalah properti, dan #433fd4 adalah nilai. Titik koma menutup deklarasi.

Satu selector boleh punya beberapa deklarasi. Tulis setiap deklarasi di baris sendiri supaya mudah dibaca.

style.css CSS 
body {  background-color: #ecedfb;  color: #1a1b33;}

background-color mengatur warna latar elemen; color mengatur warna teksnya.

Tiga cara memasang CSS

CSS bisa dipasang dengan tiga cara. Ketiganya sah, tetapi tidak sama nyamannya saat halaman bertambah besar.

1. Berkas terpisah

Simpan aturan di style.css, lalu hubungkan dari dalam <head> memakai <link>. Cara ini paling rapi karena satu berkas bisa dipakai banyak halaman.

index.html HTML 
<link rel="stylesheet" href="style.css">

rel="stylesheet" memberi tahu browser bahwa berkas tujuan berisi CSS.

2. Blok style di halaman

Untuk satu halaman atau saat sedang belajar, aturan boleh ditulis di dalam <style>. Letakkan di dalam <head>.

index.html HTML 
<style>  h1 { color: #433fd4; }</style>

3. Atribut style

Cara terakhir menempel langsung di tag. Ini cepat untuk satu elemen, tetapi paling sulit dirawat kalau dipakai banyak tempat.

index.html HTML 
<h1 style="color: #433fd4;">Profil Rani</h1>
Utamakan berkas terpisah

Untuk proyek yang tumbuh, satu style.css lebih mudah diubah daripada atribut style yang tersebar di banyak tag.

Menulis warna

Nilai warna bisa ditulis dengan nama, kode hex, atau angka RGB. Pilih satu cara dan pakai dengan konsisten.

  • Nama warna: navy, gold, tomato. Mudah dibaca, tetapi pilihannya terbatas.
  • Hex: #1a1b33. Tanda # diikuti enam digit pasangan merah, hijau, dan biru.
  • RGB: rgb(26, 27, 51). Tiga angka dari 0 sampai 255 untuk merah, hijau, dan biru.
style.css CSS 
body {  background-color: #ecedfb; /* hex */  color: rgb(26, 27, 51); /* rgb */}strong {  background-color: gold; /* nama warna */}

Kontras: teks harus tetap terbaca

Warna yang bagus bukan hanya soal selera. Teks harus cukup kontras dengan latarnya. Teks kecil minimal punya rasio kontras 4,5:1 menurut WCAG AA. Teks besar minimal 3:1.

Kuning pucat di atas putih, atau abu-abu muda di atas krem, sulit dibaca. Jangan juga memakai warna saja untuk menyampaikan arti: tambahkan teks atau ikon.

Cek dengan mata, lalu dengan alat

Lihat hasilnya di layar kecil dan besar. Kalau ragu, ukur rasio kontras memakai pemeriksa kontras di browser atau situs W3C WAI.

Latihan langsung

Beri warna halaman profil

Halaman profil di panel kiri sudah punya aturan CSS. Ganti warna latar dan warna teksnya, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Ganti background-color pada body.
  2. Ganti color pada h1 dan p.
  3. Beri background-color pada strong.
>_ profil-berwarna.html bisa diubah
Hasil pratinjau

Ubah warna di panel kiri, lalu klik Jalankan.

Cek hasil:

  • body punya background-color.
  • h1 dan p punya color.
  • strong punya background-color dan teksnya tetap terbaca.
  • Warna teks dan latar cukup kontras.

Tantangan tambahan

Warna kelasmu

Buat halaman profil baru dengan warna khas kelasmu. Pakai satu warna latar halaman, satu warna teks utama, dan satu warna sorotan untuk <strong>. Tulis aturannya di dalam <style>, lalu cek kontras teksnya.

Rangkuman

  • HTML menyusun isi; CSS mengatur tampilan.
  • Aturan CSS berisi selector, lalu blok { properti: nilai; }.
  • color mengatur warna teks; background-color mengatur warna latar.
  • CSS bisa dipasang lewat berkas .css, <style>, atau atribut style.
  • Pastikan teks dan latar punya kontras yang cukup.
