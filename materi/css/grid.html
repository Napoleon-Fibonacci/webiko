Menyusun grid

Flexbox bagus untuk satu baris. Untuk susunan kartu dua dimensi, grid lebih langsung: tentukan jumlah kolom, sisanya diatur browser.

display: grid

Grid menyusun elemen dalam baris dan kolom sekaligus. Beri display: grid pada wadah, lalu tentukan kolomnya. Anak langsung wadah otomatis mengisi sel yang tersedia.

style.css CSS 
.papan {  display: grid;  grid-template-columns: repeat(3, 1fr);  gap: 1rem;}

repeat(3, 1fr) membuat tiga kolom sama lebar. 1fr berarti satu bagian dari ruang yang ada.

Tanpa grid-template-columns, semua anak menumpuk dalam satu kolom. Jumlah kolom menentukan berapa kartu yang duduk sebaris.

Kolom yang menyesuaikan sendiri

Kalau jumlah kartu berubah atau layar mengecil, tiga kolom tetap bisa terlalu sempit. auto-fit dan minmax membiarkan browser menentukan jumlah kolom yang muat.

style.css CSS 
.papan {  display: grid;  grid-template-columns: repeat(auto-fit, minmax(8rem, 1fr));  gap: 1rem;}

Tiap kolom minimal 8rem dan boleh membesar. Kalau tidak muat, jumlah kolom berkurang sendiri.

Untuk latihan pertama, pakai tiga kolom tetap dulu supaya hasilnya mudah dilihat. Pola auto-fit bisa dicoba sebagai tantangan.

Grid atau flexbox?

Flexbox paling mudah untuk satu baris menu atau tombol. Grid lebih langsung saat kamu sudah tahu bentuk susunannya, misalnya galeri tiga kolom atau halaman dengan sidebar dan isi.

Latihan langsung

Susun papan tiga kolom

Kartu di panel kiri masih menumpuk satu per baris. Ubah wadahnya menjadi grid tiga kolom, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Tambah display: grid; pada .papan.
  2. Tambah grid-template-columns: repeat(3, 1fr); pada .papan.
  3. Tambah gap: 1rem; pada .papan.
  4. Hapus margin-bottom: 1rem; pada .kartu supaya jarak diatur oleh gap.
>_ papan-kegiatan.html bisa diubah
Hasil pratinjau

Susun kartu menjadi tiga kolom, lalu klik Jalankan.

Cek hasil:

  • .papan memakai display: grid.
  • Ada tiga kolom sama lebar.
  • Jarak antarkartu 1rem dari gap, bukan margin.
  • Kartu tidak lagi menumpuk satu per baris.

Rangkuman

  • Grid mengatur baris dan kolom sekaligus.
  • grid-template-columns menentukan lebar dan jumlah kolom.
  • repeat(3, 1fr) membuat tiga kolom sama lebar.
  • gap mengatur jarak antarsel.
  • repeat(auto-fit, minmax(8rem, 1fr)) mengurangi kolom saat ruang tidak cukup.
