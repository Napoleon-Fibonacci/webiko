CSS & tata letak · Bab 6 dari 11

Kotak: margin, border, padding

Setiap elemen adalah kotak. Jarak di dalam, garis tepi, dan jarak di luar menentukan apakah isi terasa sesak atau lega.

Isi, padding, border, margin

Setiap elemen diperlakukan browser sebagai kotak. Dari dalam ke luar ada empat bagian:

  • Content: isi elemen, seperti teks atau gambar.
  • Padding: ruang kosong di dalam, antara isi dan garis tepi.
  • Border: garis tepi yang mengelilingi padding dan isi.
  • Margin: ruang kosong di luar, pemisah dengan elemen lain.
style.css CSS 
.kartu {  padding: 1.5rem;  border: 3px solid #1a1b33;  margin-bottom: 1rem;}

Padding membuat isi tidak menempel garis. Margin memberi jarak dengan kotak berikutnya.

Padding dan margin tidak sama

padding berada di dalam kotak dan ikut terkena warna latar. margin berada di luar kotak dan selalu transparan. Jika kartu terlihat sesak, tambah padding. Jika kartu terlalu rapat dengan kartu lain, tambah margin.

style.css CSS 
.kartu {  padding: 1rem 1.5rem;  margin: 0 0 1rem;}

Dua nilai berarti atas-bawah lalu kiri-kanan. Empat nilai berarti atas, kanan, bawah, kiri.

Pada tata letak blok biasa, margin vertikal bisa saling menimpa: antar dua elemen bersebelahan atau antara elemen dan induknya. Yang dipakai adalah nilai yang lebih besar, bukan jumlah keduanya. Ini disebut margin collapse. Margin antar item flexbox atau grid tidak ikut menimpa.

box-sizing: hitung dari luar

Bawaan browser memakai content-box. Artinya width hanya menghitung isi; padding dan border menambah lebar total. Kalau kartu diberi width: 100% lalu padding, hasilnya bisa meluber.

style.css CSS 
.kartu {  width: 100%;  padding: 1.5rem;  border: 3px solid #1a1b33;  box-sizing: border-box;}

Dengan border-box, width sudah termasuk padding dan border. Kartu tetap muat di dalam induknya.

Banyak proyek memasang box-sizing: border-box untuk semua elemen lewat selector *. Untuk pemula, cukup pasang pada komponen yang punya lebar dan padding sekaligus.

Latihan langsung

Bentuk kotak kegiatan

Kartu di panel kiri masih polos: isinya menempel ke tepi dan tidak punya garis. Atur kotaknya, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Tambah padding: 1.5rem; pada .kartu.
  2. Ubah border: 0 solid #1a1b33; menjadi border: 3px solid #1a1b33;.
  3. Tambah border-radius: 12px; pada .kartu.
  4. Tambah box-sizing: border-box; dan max-width: 30rem; pada .kartu.
>_ kegiatan.html bisa diubah
Hasil pratinjau

Beri padding, border, dan batas lebar, lalu klik Jalankan.

Cek hasil:

  • .kartu punya padding: 1.5rem.
  • .kartu punya border 3px solid #1a1b33.
  • Sudut kartu membulat dan lebarnya tidak melebihi 30rem.
  • Isi tidak menempel garis tepi.

Rangkuman

  • Model kotak terdiri dari content, padding, border, dan margin.
  • Padding ada di dalam dan ikut berwarna; margin ada di luar dan transparan.
  • Margin vertikal bersebelahan bisa saling menimpa.
  • box-sizing: border-box membuat width sudah termasuk padding dan border.
  • Pasang width: 100% bersama padding hanya kalau memakai border-box.
