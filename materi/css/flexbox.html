Menata dengan flexbox

Menu yang menumpuk ke bawah mudah dibuat, tetapi belum rapi. Flexbox menyusun elemen dalam satu baris dan mengatur jaraknya.

display: flex

Flexbox mengatur anak-anak sebuah elemen dalam satu baris atau satu kolom. Elemen yang diberi display: flex menjadi wadah, dan anak langsungnya menjadi item fleksibel.

style.css CSS 
.menu {  display: flex;  gap: 1rem;}

Tanpa flex, tautan menumpuk ke bawah. Dengan flex, mereka berjajar dalam satu baris.

gap memberi jarak antaritem tanpa perlu margin di setiap anak. Ini lebih rapi daripada memberi margin-right pada semua tautan.

Sumbu utama dan sumbu silang

Pada baris flex, sumbu utama berjalan mendatar dan sumbu silang berjalan menurun. justify-content mengatur posisi di sumbu utama; align-items mengatur posisi di sumbu silang.

style.css CSS 
.menu {  display: flex;  justify-content: space-between;  align-items: center;  gap: 1rem;}

space-between mendorong item ke dua ujung. center menyejajarkan tingginya.

  • flex-start: menempel di awal.
  • center: di tengah.
  • space-between: rata kiri dan kanan, sisa ruang di tengah.
  • space-around: jarak merata dengan ruang di tepi.

Biar tidak meluber

Kalau total lebar item melebihi wadah, flexbox akan mengecilkan item. Kalau isinya tidak boleh mengecil, tambahkan flex-wrap: wrap supaya item pindah ke baris berikutnya.

style.css CSS 
.menu {  display: flex;  flex-wrap: wrap;  gap: 1rem;}

Di layar sempit, item yang tidak muat turun ke baris baru. Tidak ada yang terpotong.

Untuk menu, flex-wrap: wrap adalah pengaman sederhana sebelum memakai media query di bab Tampilan di layar HP.

Latihan langsung

Susun menu jadi satu baris

Menu di panel kiri masih menumpuk ke bawah. Ubah wadahnya menjadi flexbox dan rapikan tautannya, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Tambah display: flex;, gap: 1rem;, dan flex-wrap: wrap; pada .menu.
  2. Tambah justify-content: space-between; dan align-items: center; pada .menu.
  3. Ubah .menu a agar punya padding: 0.5rem 1rem;, background-color: #d6d9fc;, border-radius: 8px;, dan text-decoration: none;.
>_ menu-sekolah.html bisa diubah
Hasil pratinjau

Sejajarkan menu dengan flexbox, lalu klik Jalankan.

Cek hasil:

  • .menu memakai display: flex.
  • Tautan berjajar mendatar dengan jarak 1rem.
  • Di layar sempit, tautan turun ke baris baru, tidak terpotong.
  • Tautan tidak lagi bergaris bawah.

Rangkuman

  • display: flex membuat anak langsungnya berjajar.
  • gap memberi jarak antaritem tanpa margin tambahan.
  • justify-content mengatur sumbu utama; align-items mengatur sumbu silang.
  • flex-wrap: wrap mencegah item terpotong di layar sempit.
  • Flexbox cocok untuk satu baris; susunan dua dimensi lebih pas memakai grid.
