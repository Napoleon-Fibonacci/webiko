Mode gelap

Mode gelap bukan sekadar membalik warna. Nilai warna disimpan di variabel, lalu ditukar saat tema berubah.

Simpan warna di variabel

Variabel CSS menyimpan satu nilai dengan nama. Tulis nama variabel di :root (elemen <html>), lalu pakai dengan var(). Semua elemen mewarisi variabel itu.

style.css CSS 
:root {  --latar: #ffffff;  --teks: #1a1b33;  --garis: #1a1b33;} body {  background-color: var(--latar);  color: var(--teks);}

Nama variabel diawali dua tanda minus. Nilainya bisa berupa warna, ukuran, atau teks.

Menukar nilai untuk tema gelap

Karena warna hanya ditulis sekali di variabel, tema gelap cukup mengganti nilai variabelnya. Semua aturan yang memakai var() ikut berubah tanpa ditulis ulang.

style.css CSS 
.gelap {  --latar: #14152b;  --teks: #f1efff;  --garis: #8e8bf0;}

Kelas .gelap menimpa variabel untuk elemen itu dan turunannya.

Di Webiko, tema dipasang pada <html> lewat atribut data-tema. Selector-nya menjadi :root[data-tema="gelap"]. Tombol tema hanya mengganti atribut itu, bukan menulis ulang setiap warna.

Kontras tetap dijaga

Mode gelap bukan sekadar membalik warna. Latar gelap dengan teks putih murni bisa menyilaukan, dan abu-abu tua di atas hitam sulit dibaca. Pilih pasangan yang kontrasnya cukup, minimal 4,5:1 untuk teks biasa.

Garis tepi juga perlu variabel sendiri. Border tinta tua yang bagus di latar terang akan hilang di latar gelap, jadi nilainya ikut ditukar.

  • Latar gelap kebiruan #14152b lebih nyaman daripada hitam murni.
  • Teks #f1efff tidak sekeras #ffffff.
  • Aksen #8e8bf0 lebih terbaca di latar gelap daripada indigo tua.

Latihan langsung

Ubah profil menjadi mode gelap

Warna di panel kiri masih ditulis langsung. Pindahkan ke variabel, lalu pasang kelas gelap pada body agar seluruh halaman berubah, lalu klik Jalankan.

  1. Tambah blok :root berisi --latar: #ffffff;, --teks: #1a1b33;, --aksen: #433fd4;, --kartu: #d6d9fc;, dan --garis: #1a1b33;.
  2. Ganti warna body menjadi background-color: var(--latar); dan color: var(--teks);.
  3. Ganti warna .kartu menjadi background-color: var(--kartu);, warnanya h1 menjadi color: var(--aksen);, dan bordernya menjadi border: 2px solid var(--garis);.
  4. Tambah blok .gelap dengan --latar: #14152b;, --teks: #f1efff;, --aksen: #8e8bf0;, --kartu: #262a52;, dan --garis: #8e8bf0;.
  5. Ubah tag <body> menjadi <body class="gelap">.
>_ profil-kelas.html bisa diubah
Hasil pratinjau

Pindahkan warna ke variabel, lalu pasang kelas gelap pada body.

Cek hasil:

  • Warna halaman diatur lewat variabel di :root.
  • Blok .gelap menimpa nilai variabel.
  • Latar halaman menjadi gelap dan teks tetap terbaca.
  • Border kartu tetap terlihat di latar gelap.

Rangkuman

  • Variabel CSS ditulis dengan awalan -- dan dipakai lewat var().
  • Variabel di :root diwarisi semua elemen.
  • Tema gelap cukup menimpa nilai variabel, bukan menulis ulang semua aturan.
  • Webiko memakai atribut data-tema pada <html>.
  • Jaga kontras teks minimal 4,5:1; jangan pakai hitam dan putih murni tanpa alasan.
