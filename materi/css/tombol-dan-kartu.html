Tombol dan kartu

Tombol dan kartu dipakai berulang. Daripada menyalin aturan ke setiap elemen, buat satu kelas komponen yang bisa dipakai di mana saja.

Komponen adalah kelas yang dipakai ulang

Tombol dan kartu muncul berkali-kali. Daripada menulis aturan yang sama di setiap elemen, buat satu kelas komponen. Saat tampilannya perlu diubah, cukup ubah satu aturan dan semua pemakaian ikut berubah.

profil.html HTML 
<a class="tombol" href="#">Daftar</a><a class="tombol" href="#">Lihat jadwal</a>

Dua tautan memakai kelas yang sama. Tampilannya diatur sekali di CSS.

Membentuk tombol

Tautan bisa dibuat terlihat seperti tombol dengan padding, border, latar, dan sudut membulat. display: inline-block membuat padding berlaku penuh pada tautan.

style.css CSS 
.tombol {  display: inline-block;  padding: 0.75rem 1.25rem;  border: 3px solid #1a1b33;  border-radius: 12px;  background-color: #433fd4;  color: #ffffff;  text-decoration: none;}

Teks putih di atas indigo, garis tinta tebal, dan sudut membulat. Ciri khas tombol Webiko.

Keadaan hover dan fokus

Tombol perlu memberi tanda saat disentuh mouse atau keyboard. :hover berlaku saat kursor di atas elemen. :focus-visible berlaku saat elemen dipilih dengan keyboard.

style.css CSS 
.tombol:hover {  background-color: #332fc4;} .tombol:focus-visible {  outline: 3px solid #1a1b33;  outline-offset: 3px;}

Jangan menghapus outline tanpa menggantinya. Pengguna keyboard butuh penanda fokus yang jelas. Pilih warna outline yang kontras dengan latar, minimal 3:1.

Untuk tombol yang benar-benar <button>, properti cursor: pointer membantu di desktop. Untuk tautan, browser sudah memakai kursor tangan.

Latihan langsung

Bentuk tombol pendaftaran

Tautan Daftar di panel kiri masih tampak seperti teks biasa. Ubah menjadi tombol dan beri keadaan hover serta fokus, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Tambah display: inline-block;, padding: 0.75rem 1.25rem;, dan text-decoration: none; pada .tombol.
  2. Tambah border: 3px solid #1a1b33;, border-radius: 12px;, background-color: #433fd4;, dan color: #ffffff; pada .tombol.
  3. Tambah aturan .tombol:hover { background-color: #332fc4; }.
  4. Tambah aturan .tombol:focus-visible { outline: 3px solid #1a1b33; outline-offset: 3px; }.
>_ kegiatan-sekolah.html bisa diubah
Hasil pratinjau

Ubah tautan menjadi tombol, lalu klik Jalankan.

Cek hasil:

  • .tombol punya padding dan tampil sebagai inline-block.
  • Latar tombol indigo dengan teks putih dan garis tinta.
  • Tautan tidak lagi bergaris bawah.
  • Saat fokus keyboard, muncul garis tinta di luar tombol.

Rangkuman

  • Komponen adalah kelas yang bisa dipakai ulang di banyak elemen.
  • display: inline-block membuat padding berlaku penuh pada tautan.
  • Beri tombol latar, teks kontras, border, dan sudut membulat.
  • :hover menandai saat kursor di atas elemen.
  • :focus-visible menandai fokus keyboard; jangan hilangkan tanpa pengganti.
