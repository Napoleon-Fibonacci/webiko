Ukuran dan jarak

Kartu profil sudah punya warna. Sekarang atur ukurannya supaya enak dibaca: tidak terlalu lebar, teks tidak menempel tepi, dan tetap rapi di layar kecil.

Tiga satuan yang sering dipakai

CSS punya beberapa satuan ukuran. Tiga yang paling sering dipakai adalah px, rem, dan %.

  • px (piksel): ukuran tetap. Cocok untuk garis tipis atau jarak kecil yang tidak perlu berubah.
  • rem: kelipatan ukuran huruf akar halaman. Bawaan browser 16px, jadi 2rem sama dengan 32px. Kalau pengguna memperbesar huruf, ukuran rem ikut membesar.
  • % (persen): dihitung dari elemen induknya. width: 90% berarti 90% lebar induk.
style.css CSS 
h1 {  font-size: 2rem; /* 32px saat akar 16px */}.kartu {  max-width: 90%; /* tidak lebih lebar dari induk */}p {  margin-top: 16px; /* tetap 16px */}

rem dan % lebih lentur; px memberi ukuran yang tetap.

Untuk teks dan jarak antarbagian, biasakan memakai rem. Untuk lebar yang harus mengikuti layar, pakai %. Simpan px untuk hal kecil yang memang tidak perlu berubah.

Lebar, tinggi, dan batas lebar

width mengatur lebar elemen dan height mengatur tingginya. Untuk kotak berisi teks, hindari height tetap: saat teks membungkus di layar kecil, isinya bisa terpotong. Biarkan tinggi mengikuti isi.

max-width memberi batas lebar tanpa mengunci ukurannya. Elemen tetap menyusut saat layar sempit, lalu berhenti melebar saat mencapai batas.

style.css CSS 
.kartu {  width: 100%;  max-width: 32rem;}

Lebar mengikuti ruang yang ada, tetapi tidak pernah lebih dari 32rem.

Lebar tetap vs batas lebar

width: 32rem memaksa lebar 32rem di semua layar, sehingga bisa melewati tepi di HP. max-width: 32rem lebih aman karena elemen boleh menyusut.

Padding: ruang di dalam

padding memberi jarak di dalam elemen, antara isi dan tepinya. Warna latar ikut mengisi area padding, jadi teks tidak menempel ke pinggir kartu.

Satu nilai berlaku untuk keempat sisi. Dua nilai berarti atas-bawah lalu kiri-kanan.

style.css CSS 
.kartu {  padding: 2rem; /* semua sisi */}body {  padding: 2rem 1rem; /* atas-bawah, kiri-kanan */}

Kartu mendapat ruang 2rem di semua sisi; halaman mendapat 2rem atas-bawah dan 1rem kiri-kanan.

Margin: ruang di luar

margin memberi jarak di luar elemen. Area margin transparan, jadi warnanya mengikuti elemen di belakangnya. Margin dipakai untuk memisahkan elemen dari elemen lain.

Untuk kartu yang punya max-width, pasang margin: 0 auto. Nilai auto membagi sisa ruang kiri dan kanan, sehingga kartu berada di tengah.

style.css CSS 
.kartu {  margin: 0 auto; /* tengah */}h1 {  margin-top: 0;}

margin: 0 auto membuat kartu di tengah. margin-top: 0 menghapus jarak bawaan judul.

Padding atau margin?

Butuh ruang agar isi tidak menempel tepi? Pakai padding. Butuh jarak antara dua elemen? Pakai margin.

Latihan langsung

Atur jarak teks profil

Teks profil di panel kiri masih menempel ke tepi dan antarbagian terlalu rapat. Atur jaraknya, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Ubah padding: 1rem; pada body menjadi 2rem 1rem;.
  2. Tambah margin-bottom: 1.5rem; pada h1.
  3. Tambah margin-bottom: 1rem; pada p.
>_ profil-rapi.html bisa diubah
Hasil pratinjau

Tambah jarak di panel kiri, lalu klik Jalankan.

Cek hasil:

  • body punya padding: 2rem 1rem.
  • h1 punya margin-bottom: 1.5rem.
  • p punya margin-bottom: 1rem.
  • Teks tidak menempel tepi dan antarbagian punya jarak.

Tantangan tambahan

px atau rem?

Ganti margin-bottom judul dari 1.5rem menjadi 24px. Hasilnya sama saat ukuran huruf akar 16px. Lalu tambahkan html { font-size: 20px; } dan jalankan lagi: jarak 1.5rem ikut membesar, sedangkan 24px tidak. Itu sebabnya rem lebih ramah saat pengguna memperbesar teks.

Rangkuman

  • px tetap, rem mengikuti ukuran huruf akar, dan % mengikuti elemen induk.
  • width dan height mengatur ukuran; max-width membatasi lebar tanpa mengunci ukurannya.
  • Jangan beri height tetap pada kotak berisi teks; biarkan tingginya mengikuti isi.
  • padding memberi ruang di dalam elemen; margin memberi jarak di luar elemen.
  • margin: 0 auto menengahkan elemen yang punya max-width.
