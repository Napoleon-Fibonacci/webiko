Font dan tinggi baris

Teks yang sama bisa terasa enak dibaca atau melelahkan, tergantung font dan jarak antarbaris. Bab ini mengatur keduanya.

Font: pilih keluarga, sediakan cadangan

Properti font-family menentukan jenis huruf. Browser hanya bisa memakai font yang terpasang di perangkat pengunjung, jadi tulis beberapa nama sebagai cadangan, dipisah koma.

style.css CSS 
body {  font-family: system-ui, -apple-system, "Segoe UI", sans-serif;}

Browser memakai nama pertama yang tersedia. sans-serif menjadi cadangan terakhir.

Nama font yang mengandung spasi ditulis di dalam tanda kutip, seperti "Segoe UI". Urutan dibaca dari kiri ke kanan. Kalau system-ui tidak ada, browser mencoba nama berikutnya.

  • serif: huruf berkaki, seperti Times New Roman.
  • sans-serif: tanpa kaki, seperti Arial atau Segoe UI.
  • monospace: lebar sama per huruf, cocok untuk kode.

Ukuran huruf dan ketebalan

font-size mengatur besar huruf. Satuan rem mengikuti ukuran huruf akar halaman, jadi lebih ramah saat pengguna memperbesar teks. font-weight mengatur ketebalan: 400 normal, 700 tebal, dan 900 paling tebal.

style.css CSS 
h1 {  font-size: 2rem;  font-weight: 800;} p {  font-size: 1rem;  font-weight: 400;}

Tidak semua font punya ketebalan 800 atau 900. Browser memilih yang paling dekat.

Tinggi baris menentukan kenyamanan

line-height mengatur jarak antarbaris. Untuk paragraf, nilai 1.5 sampai 1.7 biasanya enak dibaca. Untuk judul, 1.1 sampai 1.2 lebih pas karena barisnya pendek.

style.css CSS 
p {  line-height: 1.7;} h1 {  line-height: 1.2;}

Angka tanpa satuan dikalikan dengan ukuran huruf elemen. Hasilnya ikut menyesuaikan saat ukuran huruf berubah.

Hindari line-height dalam piksel untuk teks yang panjang. Kalau pengguna memperbesar huruf, jarak dalam piksel tidak ikut membesar dan baris bisa terasa sesak.

Latihan langsung

Rapikan tipografi profil

Teks profil di panel kiri memakai font pratinjau bawaan dan barisnya rapat. Ganti fontnya, rapikan jaraknya, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Tambah font-family: Georgia, serif; pada body.
  2. Ubah line-height: 1.2; pada p menjadi 1.7.
  3. Tambah font-weight: 800; pada h1.
  4. Tambah font-size: 0.875rem; pada .catatan.

Rangkuman

  • font-family berisi daftar font; browser memakai yang pertama tersedia.
  • Nama font berspasi ditulis dalam tanda kutip.
  • rem mengikuti ukuran huruf akar, jadi lebih ramah saat teks diperbesar.
  • line-height tanpa satuan adalah pengali ukuran huruf.
