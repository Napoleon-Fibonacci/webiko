Mengenal CSS

HTML menyusun isi halaman. CSS mengatur tampilannya: warna, ukuran, jarak, sampai susunan kolom. Sebelum menata apa pun, kenali dulu bentuk aturan CSS dan bagian-bagiannya.

Apa itu CSS

CSS adalah singkatan dari Cascading Style Sheets. Berkas HTML memberi tahu browser isi halaman: mana judul, mana paragraf, mana tautan. CSS lalu menentukan bagaimana isi itu digambar.

Tanpa CSS, halaman masih bisa dibaca, tetapi tampak seperti dokumen polos. Judul yang lebih besar dan tautan biru bergaris bawah di halaman HTML polos berasal dari gaya bawaan browser, bukan dari HTML.

profil.html HTML 
<h1>Profil Rani</h1><p>Aku kelas 8 di SMP Harapan.</p>

HTML hanya menyebut isi dan jenisnya. Tidak ada perintah warna di sini.

style.css CSS 
h1 {  color: #433fd4;}

CSS memilih elemen h1, lalu mengatur warna teksnya.

Memisahkan isi dan tampilan membuat halaman mudah dirawat. Isi tidak perlu disentuh saat warna berubah, dan satu berkas CSS bisa dipakai oleh banyak halaman sekaligus.

Bagian-bagian aturan CSS

CSS ditulis sebagai kumpulan aturan. Aturan biasa selalu punya pola yang sama: pilih elemen, lalu tentukan pengaturannya di dalam kurung kurawal.

style.css CSS 
/* aturan untuk semua judul h1 */h1 {  color: #433fd4;  font-size: 2rem;}

Satu aturan dengan selector, blok deklarasi, dan dua deklarasi.

  • Selector h1: memilih elemen yang akan diatur. Di sini semua elemen <h1>.
  • Blok deklarasi { ... }: kurung kurawal yang membungkus semua pengaturan untuk selector itu.
  • Deklarasi color: #433fd4;: satu pengaturan. Isinya properti, titik dua, nilai, lalu titik koma.
  • Properti color: hal yang diatur. Contoh lain: font-size dan background-color.
  • Nilai #433fd4: isi pengaturannya.
  • Komentar /* ... */: catatan untuk manusia. Browser mengabaikannya.

Satu aturan boleh punya banyak deklarasi. Tulis satu deklarasi per baris dan beri indentasi supaya mudah dibaca. Titik koma menutup setiap deklarasi.

style.css CSS 
body {  background-color: #ecedfb;  color: #1a1b33;}

Dua deklarasi pada satu aturan: latar halaman dan warna teksnya.

Selector dasar

Selector menentukan elemen mana yang kena aturan. Tiga bentuk yang paling sering dipakai adalah selector tag, kelas, dan id.

profil.html HTML 
<h1 id="profil">Profil Rani</h1><p class="sorotan">Kelas 8, SMP Harapan.</p><p>Hobi: menggambar.</p>
style.css CSS 
p { color: #3a3c7e; }.sorotan { background-color: gold; }#profil { color: #433fd4; }

p mengenai kedua paragraf, .sorotan hanya paragraf berkelas itu, dan #profil hanya judul ber-id itu.

  • Tag: tulis nama tag, mis. p. Berlaku untuk semua elemen jenis itu.
  • Kelas: diawali titik, mis. .sorotan. Satu kelas boleh dipakai di banyak elemen.
  • Id: diawali pagar, mis. #profil. Sebaiknya hanya satu elemen per halaman.

Selector bisa digabung dan diberi keadaan, misalnya .sorotan:hover. Kita bahas lebih dalam di bab Selector dan kelas.

Tiga cara memasang CSS

Aturan CSS harus dihubungkan ke HTML. Ada tiga cara, dan ketiganya sah. Bedanya ada pada kerapian saat halaman bertambah besar.

1. Berkas terpisah

Simpan aturan di style.css, lalu hubungkan dari dalam <head> memakai <link>. Satu berkas bisa dipakai banyak halaman.

index.html HTML 
<link rel="stylesheet" href="style.css">

rel="stylesheet" memberi tahu browser bahwa berkas tujuan berisi CSS.

2. Blok style di halaman

Untuk satu halaman atau saat sedang belajar, aturan boleh ditulis langsung di dalam <style> di bagian <head>.

index.html HTML 
<style>  h1 { color: #433fd4; }</style>

3. Atribut style

Cara terakhir menempel langsung di tag. Cepat untuk satu elemen, tetapi paling sulit dirawat kalau dipakai di banyak tempat.

index.html HTML 
<h1 style="color: #433fd4;">Profil Rani</h1>
Mulai dari style, lalu pindahkan

Saat belajar, <style> memudahkan karena kode ada di satu tempat. Begitu halamanmu lebih dari satu, pindahkan aturannya ke style.css supaya tidak perlu menyalin warna yang sama ke setiap halaman.

Bagaimana browser membacanya

Browser membaca aturan dari atas ke bawah. Kalau dua aturan yang sama kuatnya mengatur properti yang sama pada elemen yang sama, aturan yang ditulis belakangan yang dipakai. Inilah arti kata cascading pada CSS. Selector yang lebih khusus, misalnya id dibanding tag, bisa menang walau ditulis lebih dulu; kita bahas di bab Selector dan kelas.

Sebagian properti juga diwarisi. Warna teks dan jenis huruf yang dipasang di body ikut dipakai oleh elemen di dalamnya, kecuali ada aturan khusus yang menimpanya.

style.css CSS 
body {  color: #1a1b33; /* diwarisi anak-anaknya */}p {  color: #433fd4; /* menimpa warisan */}

Paragraf mewarisi warna body, lalu aturannya sendiri menimpa warna itu. Judul dan elemen lain tetap memakai warna warisan.

Ada juga aturan pembungkus seperti @media. Aturan di dalamnya hanya berlaku saat syaratnya terpenuhi, misalnya lebar layar minimal 600px. Kita pakai di bab Tampilan di layar HP.

Latihan langsung

Halaman profil pertama

Panel kiri berisi satu halaman dengan blok <style>. Ubah dan tambah aturannya, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Ganti nilai color pada h1 menjadi #433fd4.
  2. Tambah deklarasi text-align: center; di dalam aturan h1.
  3. Tambah aturan baru p { color: #3a3c7e; }.
>_ profil-pertama.html bisa diubah
Hasil pratinjau

Ubah dan tambah aturan di panel kiri, lalu klik Jalankan.

Cek hasil:

  • h1 punya dua deklarasi: color dan text-align.
  • Ada aturan terpisah untuk p.
  • Setiap deklarasi diakhiri titik koma dan kurung kurawalnya lengkap.
  • Pratinjau berubah setelah Jalankan diklik.

Tantangan tambahan

Pindahkan ke berkas sendiri

Buat profil.html dan style.css di komputer. Pindahkan semua aturan dari <style> ke style.css, lalu hubungkan dengan <link rel="stylesheet" href="style.css">. Tambahkan satu komentar /* ... */ di atas aturan h1, lalu buka halamannya di browser.

Rangkuman

  • HTML menyusun isi; CSS mengatur tampilan.
  • Satu aturan berisi selector, lalu blok deklarasi { properti: nilai; }.
  • Selector tag berlaku untuk semua elemen sejenis, kelas (diawali .) bisa dipakai berulang, id (diawali #) untuk satu elemen.
  • CSS dipasang lewat berkas .css, blok <style>, atau atribut style. Utamakan berkas terpisah saat halaman bertambah.
  • Aturan yang ditulis belakangan menimpa aturan sebelumnya, dan sebagian properti diwarisi dari elemen induk.
