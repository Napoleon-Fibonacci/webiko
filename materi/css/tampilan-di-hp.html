Tampilan di layar HP

Halaman yang rapi di laptop bisa berantakan di HP. Lebar layar berubah, jadi tata letak perlu satu aturan tambahan.

Viewport: beri tahu browser lebar layar

Semua halaman Webiko sudah punya satu baris ini di dalam <head>:

profil.html HTML 
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Tanpa meta viewport, HP menganggap halamannya selebar desktop lalu mengecilkannya. Teks jadi kecil dan tombol sulit disentuh.

Dengan width=device-width, lebar halaman mengikuti lebar layar perangkat. Media query baru bisa bekerja seperti yang diharapkan.

Media query

Media query menjalankan aturan CSS hanya pada kondisi tertentu. Untuk layar sempit, pakai max-width. Artinya aturan berlaku selama lebar layar tidak lebih besar dari nilai itu.

style.css CSS 
@media (max-width: 40rem) {  .kolom {    grid-template-columns: 1fr;  }}

Di bawah 40rem (sekitar 640px), dua kolom berubah menjadi satu kolom.

Cara lain adalah mobile-first: tulis tampilan HP sebagai bawaan, lalu tambahkan @media (min-width: 40rem) untuk layar lebar. Keduanya benar; yang penting konsisten.

Gambar dan teks yang lentur

Gambar besar bisa membuat halaman melebar. Batasi lebarnya supaya mengikuti wadah:

style.css CSS 
img {  max-width: 100%;  height: auto;}

Gambar tidak akan melebihi lebar wadahnya, dan tingginya menyesuaikan tanpa gepeng.

Hindari lebar tetap seperti width: 1200px pada elemen utama. Pakai max-width dan satuan relatif agar halaman ikut menyempit.

Latihan langsung

Susun ulang kartu di layar sempit

Dua kartu di panel kiri berjajar di layar lebar. Tambahkan media query supaya menjadi satu kolom di layar HP, lalu klik Jalankan. Jangan ubah isi HTML-nya.

  1. Tambah @media (max-width: 40rem) { ... } di akhir CSS.
  2. Di dalamnya, ubah .kolom menjadi grid-template-columns: 1fr;.
  3. Di dalamnya juga, ubah h1 menjadi font-size: 1.5rem;.
  4. Perkecil jendela browser sampai di bawah 40rem untuk melihat hasilnya.
>_ kartu-kegiatan.html bisa diubah
Hasil pratinjau

Tambah media query, lalu perkecil jendela browser.

Cek hasil:

  • Di layar lebar, dua kartu tetap berjajar.
  • Di bawah 40rem, kartu menjadi satu kolom.
  • Judul ikut mengecil di layar sempit.
  • Tidak ada isi yang terpotong di lebar 320px.

Rangkuman

  • Meta viewport membuat lebar halaman mengikuti lebar layar perangkat.
  • Media query max-width berlaku di layar yang tidak lebih lebar dari nilai itu.
  • Mobile-first memakai min-width untuk menambah gaya di layar lebar.
  • max-width: 100% mencegah gambar melebar keluar wadah.
  • Uji halaman di lebar 320px, 390px, dan desktop, bukan hanya di satu ukuran.
